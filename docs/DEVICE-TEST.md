# Cardputer Zero device and package review

Only the M5Stack Cardputer Zero Linux ARM64 target is in scope. Do not flash an image or change the OS or its permissions for this app.

## Build a candidate locally

Use the versioned [release recipe](RELEASING.md) for the pinned BSP, exact package icon and approved maintainer.

1. Obtain a project-isolated GNU `aarch64-linux-gnu-gcc/g++` toolchain and the official [v0.0.4 BSP sysroot](https://github.com/CardputerZero/launcher/releases/tag/v0.0.4). The published BSP is 435,042,027 bytes compressed with SHA-256 `e51b6eb803ed08f450e459efbfe62dd0341440846f3be9d01da861fe6cfdebb0`; verify it before extracting. On a host without a cross compiler, use an isolated Debian 13 builder with GNU ARM64 cross tools, CMake/Ninja and dpkg tooling instead of modifying the host OS. The CMake toolchain defaults to no automatic SDK download; pass the existing verified sysroot. The stock Launcher requires an existing user session with framebuffer, keyboard and local PulseAudio access; this program does not add group permissions or a systemd service.
2. Configure with `-DCMAKE_TOOLCHAIN_FILE=cmake/cardputerzero-aarch64.cmake -DCM0_SDK_ROOT=/path/to/bsp -DCW_CARDPUTER_ZERO=ON -DCMAKE_BUILD_TYPE=Release`, using a fresh `build/cardputerzero` directory. Put the approved cross tools on this command's PATH, not in global configuration.
3. To generate a .deb, first make a local 256 × 256 PNG from the source icon, for example `mkdir -p build/package && convert -background none packaging/icon.svg build/package/cwtrainerzero.png`. Configure with the same options plus `-DCW_ENABLE_DEB=ON -DCW_APP_ICON="$PWD/build/package/cwtrainerzero.png" -DCW_DEB_MAINTAINER="$CW_MAINTAINER"`. Supply the approved public maintainer name and email (`Name <address>`) in that shell variable. The project leaves the maintainer unset; do not use a sample value or put the contact into Git without approval. Build then use `cpack --config build/cardputerzero/CPackConfig.cmake -B build/package -G DEB`.
4. Before installation, inspect the .deb with `dpkg-deb -I` and `dpkg-deb -c` and verify ELF AArch64 architecture/library dependencies, launcher target/icon and checksums. The only shared paths are package-specific entries `/usr/share/APPLaunch/applications/cwtrainerzero.desktop` and `/usr/share/APPLaunch/share/images/cwtrainerzero.png`; docs are under `/usr/share/doc/cwtrainerzero`; no postinst, services, credentials or global settings. Check `dpkg-deb -f package.deb Maintainer` displays the approved public contact, not a placeholder. Verify the actual package contains `LICENSE`, `THIRD-PARTY-NOTICES.md` and the four license files under `licenses/` (CardputerZero Template, LVGL, Montserrat, miniaudio) in its own documentation directory; the CMake install entries alone are not release proof.

## Physical acceptance (not yet done)

With the owner's permission, open the candidate through APPLaunch on a stock Cardputer Zero. Verify an intact 320 × 170 view and short one-handed control path; real Space, A–Z (including plain Z/C), Enter, Backspace, arrows, 0, Tab and Esc; speaker and headset audio at low volume; at least ten pairs and repeated/rapid replay; no clipping at start or end; no phantom submit mid-tone; and restart persistence at the selected speed and lesson level. Verify Settings (Fn+1), group-size extremes 1 and 4, and each practice set. Confirm bare 0 types zero in Numbers but is the A–Z shortcut in Letters. Verify direct physical punctuation (including Sym shortcuts where printed) and arrow/Tab fallback for all five symbols. Play a partially correct group and confirm matched characters count even if the whole group was incorrect. Check that prior profile migration preserves group totals/letter level and leaves the old file intact; use a disposable test profile for migration. Do a short run with network intentionally unavailable; audio must use the system's local default route. If a keyboard is not found, first verify the session's ordinary input permissions and the device's evdev codes. The program also accepts a specific reported `--keyboard /dev/input/eventN` for local diagnosis; do not run the whole app as root to work around file access.

The native punctuation mapping follows the official [FactoryTest TCA8418 event mapping](https://github.com/CardputerZero/FactoryTest/blob/aec90d383ea7bf046f16ec5c55909b4b4b98cf94/src/platform/linux_input.cpp#L511-L527). A platform mapping is not physical validation: the arrow/Tab picker works without direct symbols.

## First-release demo (not yet recorded)

The [packages publishing lifecycle](https://github.com/CardputerZero/packages/blob/main/docs/PUBLISHING.md) lists a human review and device demo for first releases through either the CLI or web portal. The [AppBuilder schema](https://github.com/CardputerZero/AppBuilder/blob/main/docs/APP_BUILDER_JSON.md) specifies a short video of the app on real hardware, posted in the submission PR comments after the PR opens. A desktop simulator clip does not meet that requirement. The official docs do not specify an exact duration or shot list.

Record one short sequence on the physical Cardputer Zero after the exact candidate passes the checks above: open **CWTrainerZero** in APPLaunch, press Space to play an audible pair and replay it, show the K/M keystrokes and Enter feedback, exit, then reopen to show the saved score and speed. Keep screen and keys visible, and record the actual device audio rather than adding a replacement signal. Use only demo data, avoid filming identifying details, and keep the clip out of source control. Save the clip beside the exact package version and checksum. Sharing the clip and submitting a release remain separate approval steps.

## Later submission

Separate approval is required for creating or publishing a public GitHub repo, uploading to the store, or installing on a device. Review all source via `scripts/check-source-export.sh` against the exact Git index, then inspect archive contents. Keep the reviewed ARM64 package, source revision and package SHA. Confirm the unique package name/share code, approved maintainer and public identity, app icon, 320 × 170 screenshot and category in the [official App Builder](https://dev.cardputer.cc/). Suggested summary: “Offline Morse code practice for Cardputer Zero.” No app background service, microphone, radio, network feature or camera needed. Do not use the template's deployment script or unreviewed publishing workflow.
